# 环境搭建

## 环境信息

- 操作系统：Rocky Linux
- 虚拟机 IP：192.168.149.128
- Web 服务器：Nginx
- 应用服务器：Tomcat（默认端口 8080）
- 访问入口：宿主机浏览器访问 http://192.168.149.128
- 最终效果：Nginx 监听 80 端口，反向代理到 Tomcat 的 8080 端口，宿主机浏览器正常访问

## 1. 安装 Nginx

- dnf install -y nginx
  使用 dnf 包管理器安装 Nginx

- systemctl start nginx
  启动 Nginx 服务

- systemctl enable nginx
  设置 Nginx 开机自启

- systemctl status nginx
  确认 Nginx 状态为 active（running）

## 2. 安装 Tomcat

- 下载 JDK 与 Tomcat 压缩包
  上传或下载到 /usr/local 目录

- 解压
  tar -zxvf 包名

- 配置 JDK 环境变量
  在 /etc/profile 中配置 JAVA_HOME，例如：
  export JAVA_HOME=/usr/local/jdk
  export PATH=$JAVA_HOME/bin:$PATH
  配置后执行 source /etc/profile 使其生效

- 准备 Tomcat 的 systemd 服务文件
  在 /usr/lib/systemd/system/tomcat.service 中编写服务配置
  核心内容：指定 CATALINA_HOME、启动用户、ExecStart 与 ExecStop 路径
  然后执行：
  systemctl daemon-reload
  重新加载 systemd 配置

- 启动 Tomcat
  systemctl start tomcat
  systemctl enable tomcat

- 验证 Tomcat 启动
  systemctl status tomcat
  看到 active（running）且无报错，说明启动正常

  ss -lntp | grep 8080
  看到 8080 端口被监听，说明进程已正常监听

## 3. 防火墙放行

- firewall-cmd --add-port=8080/tcp --permanent
  放行 8080 端口，宿主机才能访问 Tomcat

- firewall-cmd --reload
  重新加载防火墙规则，使其生效

- firewall-cmd --list-all
  确认 8080 端口已出现在放行列表中

## 4. 验证 Tomcat 可访问

- 在宿主机浏览器访问：
  http://192.168.149.128:8080

- 能打开 Tomcat 默认页面，说明 Tomcat 安装、启动、防火墙放行全部正常

## 5. 踩坑记录

- 端口未放行导致访问失败
  现象：浏览器打不开，连接超时
  排查：firewall-cmd --list-all 发现 8080 未放行
  解决：add-port 后 reload

- 服务启动失败时先查日志
  命令：journalctl -u tomcat -n 50
  用于快速看到 Tomcat 启动报错的最后 50 行
