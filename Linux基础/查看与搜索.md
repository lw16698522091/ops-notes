# 查看与搜索

## 1. 查看文件内容
| 命令 | 作用 |
|------|------|
| cat 文件名 | 一次性显示文件全部内容；适合查看较短的配置文件，例如 cat /etc/hosts |
| less 文件名 | 分页查看大文件；按空格翻页，按 q 退出；适合查看较长的日志或文档 |

## 2. 查看文件头部或尾部
| 命令 | 作用 |
|------|------|
| head 文件名 | 默认显示前 10 行；示例：head -5 文件名 显示前 5 行 |
| tail 文件名 | 默认显示后 10 行；示例：tail -50 文件名 显示后 50 行 |
| tail -f 文件名 | 实时跟踪文件新增内容；排障时常用它盯日志，例如 tail -f /var/log/nginx/error.log；退出时按 Ctrl + C |

## 3. 搜索文件内容

- grep 关键字 文件名

  在文件中查找包含关键字的行

  示例：grep error /var/log/nginx/error.log

  常用选项：

  - grep -v：排除匹配行

  - grep -i：忽略大小写

  - grep -r：递归搜索目录下所有文件

## 4. 查找文件

- find 路径 -name 文件名

  按名称查找文件

  在静态资源 404 演练中，用它按名称查找真实存在的图片文件，再和 Nginx 日志里的路径做对比

  示例：find / -name "test.png"

- find 路径 -size 大小

  按文件大小查找

  在磁盘满演练中，用 find / -xdev -size +200M 查找超过 200M 的大文件

  说明：-xdev 表示不跨文件系统，避免去扫描 /proc 等虚拟目录

- find 路径 -mtime 天数

  按修改时间查找

  示例：find /var/log -mtime +7 查找 7 天前修改的文件，可用于日志清理

## 5. 查看目录占用量

- du -sh 目录

  统计目录总大小

  在磁盘满演练中，用 du -sh /var 逐级确认是哪个目录占用空间最大

## 6. 定位命令所在路径

- which 命令名

  显示命令的绝对路径

  在 crontab 无人值守排障中，用 which mysqldump 确认定时任务里找不到的命令是否存在、在哪个目录

  配合 echo $? 判断前一条命令是否执行成功

- echo $?

  显示上一条命令的退出码

  0 表示成功，非 0 表示失败

  退出码 127 通常表示命令找不到

## 7. 路径逐层检查

- namei -l 完整路径

  逐层显示路径中每一级目录是否存在、权限是否正常

  在静态资源 404 演练中，用它从根目录开始逐层检查，定位到断在哪一层

  示例：namei -l /var/www/html/image/test.png
