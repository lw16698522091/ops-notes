# Shell 基础语法

脚本编写的基础语法整理，配合实战脚本理解。

## 脚本开头

```bash
#!/bin/bash
# 上面这行叫 shebang，告诉系统用哪个解释器执行
```

## 变量

```bash
name="value"      # 赋值（等号两边不能有空格）
echo $name        # 引用变量
echo ${name}      # 推荐：花括号形式，避免歧义
readonly PI=3.14  # 只读变量
```

## 特殊变量

| 变量 | 含义 |
|------|------|
| `$0` | 脚本自身名称 |
| `$1`~`$9` | 第 1~9 个参数 |
| `$#` | 参数个数 |
| `$?` | 上一条命令的退出码 |
| `$$` | 当前进程 PID |

## 条件判断

```bash
if [ -f "$file" ]; then
    echo "是文件"
elif [ -d "$dir" ]; then
    echo "是目录"
else
    echo "其他"
fi
```

常用测试：
- `-f` 文件存在；`-d` 目录存在；`-x` 可执行
- `-eq` 等于；`-ne` 不等于；`-gt` 大于

## 循环

```bash
# for 循环
for i in 1 2 3; do
    echo $i
done

# while 循环
while [ $count -lt 5 ]; do
    count=$((count + 1))
done
```

## 函数

```bash
backup() {
    local src=$1
    tar -czf backup.tar.gz "$src"
}
backup /data
```

## 实战：备份脚本骨架

```bash
#!/bin/bash
export PATH=/usr/local/mysql/bin:/usr/bin:/bin   # 补全 PATH

SRC="/data"
DEST="/backup/$(date +%F).tar.gz"

tar -czf "$DEST" "$SRC"
echo "退出码：$?"
```

## 使用要点
- 变量引用一律加双引号 `"$var"`，防止空格/特殊字符出问题
- `[ ]` 括号两边留空格，否则语法报错
- 脚本写完后 `bash -n script.sh` 先做语法检查，再执行
- PATH 补全放在脚本开头，避免 cron 执行时找不到命令（cron 环境变量问题详见[基础语法](基础语法.md)中的执行与调试说明，以及[定时任务排障](../定时任务/crontab排障.md)）
