# Shell 基础语法

> 本模块记录 Shell 脚本的基础语法，并结合实际练习中遇到的问题，说明每个语法点在运维脚本编写中的用途。
> 目标：能独立看懂并编写简单的运维脚本，为后续编写自动化脚本打基础。

---

## 一、基础语法速查

| 语法 | 作用 | 常用写法 / 示例 |
|------|------|-----------------|
| `#!/bin/bash` | 指定解释器，必须写在脚本第一行 | `#!/bin/bash` |
| `变量=值` | 定义变量，等号两边不能有空格 | `name="nginx"` |
| `$变量` | 引用变量 | `echo $name` |
| `$?` | 查看上一条命令的退出码，0 成功，非 0 失败 | `echo $?` |
| `$1 $2` | 获取脚本或函数的第一个、第二个参数 | `bash test.sh nginx mysql` |
| `read` | 读取用户输入存入变量 | `read -p "请输入：" name` |
| `if` | 条件判断，支持多分支 | `if [ $a -eq $b ]; then ... fi` |
| `[ 条件 ]` | 条件表达式，注意左右空格 | `[ $a -eq $b ]` |

## 二、数值与字符串比较

### 1. 数值比较

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `-eq` | 等于 | `[ $a -eq $b ]` |
| `-ne` | 不等于 | `[ $a -ne $b ]` |
| `-gt` | 大于 | `[ $a -gt $b ]` |
| `-lt` | 小于 | `[ $a -lt $b ]` |
| `-ge` | 大于等于 | `[ $a -ge $b ]` |
| `-le` | 小于等于 | `[ $a -le $b ]` |

### 2. 字符串比较

| 运算符 | 含义 | 示例 |
|--------|------|------|
| `=` 或 `==` | 相等 | `[ "$str" = "ok" ]` |
| `!=` | 不相等 | `[ "$str" != "ok" ]` |
| `-z` | 字符串为空 | `[ -z "$str" ]` |

### 3. if 语法结构

if [ 条件 ]; then
命令
elif [ 条件 ]; then
命令
else
命令
fi

**注意点**：

- `[` 后面和 `]` 前面必须有空格
- `then` 前面用分号，或换行写 `then`
- 结尾必须是 `fi`
- 字符串比较时用双引号包变量，防止变量为空报错

## 三、交互输入

### read 基本用法
read -p "提示文字" 变量名

示例：
read -p "请输入服务名称：" service
echo "你输入的服务是：$service"

**说明**：
- `-p` 输出提示文字
- 变量名不需要提前定义
- 输入回车后内容存入变量

## 四、脚本执行与调试
### 1. 执行方式

chmod +x test.sh
./test.sh

或直接使用 bash 执行，无需执行权限：
bash test.sh

### 2. 调试方式
bash -x test.sh
会逐行输出展开后的实际执行命令，快速定位哪一行出错。

## 五、踩坑记录
### 1. `$?` 不能单独执行
`$?` 是变量不是命令，直接敲 `$?` 会被 Shell 展开成退出码，然后当作命令执行，报命令未找到。

**正确写法**：
echo $?

### 2. 变量定义不能加引号
定义数值变量时加引号（如 `i="1"`），会导致后续 while 数值比较失败，循环不执行，脚本无输出但退出码为 0。
**定位方法**：使用 `bash -x` 调试，会看到 `unary operator expected`（需要一元运算符）报错。

### 3. 条件判断的引号问题
字符串比较时变量加双引号更安全：
推荐写法
if [ "$2" = "running" ]; then
不推荐写法，变量为空时语法报错
if [ $2 = running ]; then

## 六、写脚本时学到的知识点
1. 绝对路径与相对路径的区别
- /opt 和 /home/admin/opt 是两个完全不同的目录。
- ls / 可看到根目录下一级目录，/opt 是根目录下的目录，与家目录无关。
- 脚本中定位源目录和目标目录必须使用绝对路径，不能用 ./ 或 ~ 开头拼路径，否则取决于执行时的工作目录。

2. 通配符与引号
- 双引号内通配符 * 不会展开。ls -t "/backup/myapp*.tar.gz" 会把 * 当普通字符，查找名为 myapp.tar.gz 的字面文件，所以失败。
- 路径中无空格时，带通配符的模式不要整体加引号，直接写 ls -t /backup/myapp_.tar.gz 即可。
- 变量加引号与通配符规则无关，变量要加双引号防止空格拆分。

3. 脚本开头设置 PATH
- cron 环境的 PATH 很少，建议在脚本开头加上：export PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
- cron 内加上也能使用，但放脚本开头更稳妥
- 注意必须包含 sbin 路径，否则 fdisk、service 等管理命令可能找不到。

4. mkdir -p 用法
- mkdir -p 目录 在目录不存在时创建，已存在时不报错且返回 0，创建失败返回非 0。
- 因此可以用 if mkdir -p /backup; then ... else ... fi 直接判断，不需要先写 if [ ! -d ] 再创建。

5. find 与数量限制
- find 本身没有限制结果数量的参数，需要配合 head 或 tail 使用。
- 按数量删除旧备份时，用 ls -t | tail -n +8 | xargs rm -f 更直接。

---

## 七、学习要点
- 变量名等号两边不能有空格，这是最容易犯的低级错误。
- 脚本第一行 `#!/bin/bash` 不能省略。
- `bash -x` 是调试 Shell 脚本最重要的工具，不会调试等于瞎猜。
- 所有语法都要动手敲一遍，只看不练很容易忘。
