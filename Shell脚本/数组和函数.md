# Shell 函数与数组

> 本模块记录 Shell 脚本中函数的定义调用、参数传递、返回值、命令替换，以及数组的定义、取值、遍历和多数组对齐等内容。
> 目标：能把重复逻辑封装成函数，能用数组管理批量数据，写出结构清晰的运维脚本。

---

## 一、基础语法速查

| 语法 | 作用 | 常用写法 / 示例 |
|------|------|-----------------|
| `函数名() { ... }` | 定义函数 | `log_msg() { echo "[INFO] $1"; }` |
| `函数名 参数` | 调用函数 | `log_msg "服务启动中"` |
| `$1 $2` | 函数内获取参数 | `echo $1` |
| `return` | 返回退出码（0-255） | `return 0` |
| `$(...)` | 命令替换，捕获输出到变量 | `log=$(log_msg "启动")` |
| `数组名=(...)` | 定义数组，空格分隔 | `arr=("a" "b" "c")` |
| `${arr[0]}` | 取单个元素，下标从 0 | `echo "${arr[0]}"` |
| `${arr[@]}` | 取全部元素 | `for s in "${arr[@]}"; do ...` |
| `${#arr[@]}` | 获取数组长度 | `echo "${#arr[@]}"` |

## 二、函数

### 1. 定义与调用
log_msg() {
echo "[INFO] $1"
}

log_msg "服务启动中"
log_msg "服务停止中"

输出结果：
[INFO] 服务启动中
[INFO] 服务停止中

**说明**：
- 函数名后加 `()`，花括号内写函数体
- 函数必须先定义后调用，通常把函数写在脚本开头
- 调用时函数名后直接跟参数，不加括号

### 2. 多参数传递
```
info() {
echo "[INFO] $1 $2"
}

warn() {
echo "[WARN] $1 $2"
}

error() {
echo "[ERROR] $1 $2"
}

info "nginx" "running"
warn "mysql" "stopped"
error "redis" "error"
```
输出结果：
[INFO] nginx running
[WARN] mysql stopped
[ERROR] redis error

**说明**：函数内用 `$1`、`$2` 依次接收参数，调用时按顺序传入。

### 3. 返回值
```
check_disk() {
if [ "$1" -gt 100 ]; then
return 1
else
return 0
fi
}

check_disk 50
echo "返回值：$?"
check_disk 150
echo "返回值：$?"
```
输出结果：
返回值：0
返回值：1

**说明**：
- `return` 只能返回 0-255 的数字，通常 0 表示成功，非 0 表示失败或自定义状态
- 调用函数后紧跟 `echo $?` 获取返回值
- `return` 返回的是状态码，不是输出内容

### 4. 命令替换
log_msg() {
echo "[INFO] $1"
}

i=$(log_msg "nginx running")
echo "$i"

输出结果：
[INFO] nginx running

**说明**：

- `$(...)` 会先执行括号内的函数，把 `echo` 的输出捕获到变量 `i` 中，不会打印到屏幕
- 需要同时获取输出和返回值时，分开处理：

i=$(check_service "nginx" "running")
echo "日志内容：$i"
echo "返回状态：$?"

## 三、数组

### 1. 定义与取值
servers=("nginx" "mysql" "redis")
echo "第一个：${servers[0]}"
echo "全部：${servers[@]}"
echo "数量：${#servers[@]}"

输出结果：
第一个：nginx
全部：nginx mysql redis
数量：3

**注意**：数组用空格分隔，不能用逗号；取下标元素时花括号不能省略。

### 2. for 遍历
servers=("nginx" "mysql" "redis")
for s in "${servers[@]}"; do
echo "服务：$s"
done

输出结果：
服务：nginx
服务：mysql
服务：redis

### 3. while + 下标遍历
servers=("nginx" "mysql" "redis")
i=0
while [ i−lt{#servers[@]} ]; do
echo "{servers[i]}"
i=$((i+1))
done

## 四、综合示例：函数 + 数组

定义一个检查服务状态的函数，遍历服务数组批量检查：
check_service() {
if [ "$2" = "running" ]; then
echo "[INFO] $1 is running"
elif [ "$2" = "stopped" ]; then
echo "[WARN] $1 is stopped"
else
echo "[ERROR] $1 unknown status"
fi
}

services=("nginx" "mysql" "redis")
statuses=("running" "stopped" "error")
i=0
while [ i−lt{#services[@]} ]; do
check_service "{services[i]}" "{statuses[i]}"
i=$((i+1))
done

输出结果：
[INFO] nginx is running
[WARN] mysql is stopped
[ERROR] redis unknown status

**说明**：用同一个下标 `$i` 同时取两个数组的对应元素，保证服务和状态始终正确对应。

## 五、踩坑记录

### 1. return 和 echo 混用

`return` 只返回退出码，不会把内容输出到变量。想捕获函数输出必须用 `echo` 配合 `$(...)`：

错误写法，result 拿到的是空值
get_name() {
return "nginx"
}

result=$(get_name)

正确写法
get_name() {
echo "nginx"
}

result=$(get_name)

### 2. 数组用逗号分隔

错误写法，逗号会被当成元素的一部分
arr=("a","b","c")

正确写法，用空格分隔
arr=("a" "b" "c")

### 3. 数组取值省略花括号

错误写法，$servers[0] 会被解释为变量 servers[0]
echo $servers[0]

正确写法
echo "${servers[0]}"

### 4. 函数参数和脚本参数混淆

函数内的 `$1`、`$2` 指的是调用函数时传的参数，不是执行脚本时传的参数。如果在函数里需要脚本的参数，要在函数外先保存：

script_arg=$1
my_func() {
echo "脚本参数：$script_arg"
echo "函数参数：$1"
}

## 六、写脚本时学到的数组进阶
### 关联数组
- 使用前必须先声明：declare -A usage。关联数组可以用字符串作下标，比如 usage[cpu]、usage[mem]。
- 遍历关联数组键
- for key in "${!usage[@]}"; do echo "$key: ${usage[$key]}"; done
- 加感叹号表示取所有键而不是值。遍历普通数组索引同理。数组展开必须加双引号，防止键或值含空格时拆分。

### 数组长度
- ${#array[@]} 是数组元素个数。判断数组是否为空用 [ "${#array[@]}" -gt 0 ]。注意 ${!array[@]} 是索引列表，不是长度。

### 中文键
- 语法支持中文键，但可能出现编码问题，不推荐。可以用英文键加标签映射：
- declare -A label
- label[cpu]="CPU使用率"
- label[mem]="内存使用率" 
- 然后在打印时用 ${label[$key]} 显示中文，键本身保持英文。

### 并行与数组传递
- () &包裹内置于后台运行，配合循环外wait，等待后台运行结束
- 后台子 shell 中不能直接往父 shell 的数组追加内容。
- 并行脚本流程：mktemp -d 创建临时目录，后台子 shell 中把结果 echo 追加到文件，wait 后使用 mapfile -t 数组名 < 文件 把文件按行读入数组，最后 rm -rf 临时目录。

## 七、学习要点

- 函数是复用逻辑的基本单元，把重复代码封装成函数，脚本更清晰。
- `echo` 负责输出内容，`return` 负责返回状态，两者用途不同不能混用。
- 需要函数返回复杂结果时，用 `echo` 输出 + `$(...)` 捕获。
- 数组下标从 0 开始，花括号 `${arr[0]}` 不能省。
- 多个数组要一一对应时，用计数器下标遍历，比硬编码更健壮。
